# Plus UI Pro - Jekyll Theme for GitHub Pages

Professional Jekyll theme inspired by Plus UI Blogger Template.

## Features

- 🎨 Color Switcher (8 presets + custom)
- 🌓 Dark/Light/Auto mode
- 💬 Comments: Giscus, Utterances, Disqus
- 🔍 Instant Search (Ctrl+K)
- 📱 PWA Ready
- 📚 RTL Arabic Support
- ⚡ Fast & SEO Optimized
- 🎯 Plus UI Cards Design

## Quick Start

1. Fork this repo as `USERNAME.github.io`
2. Edit `_config.yml`
3. Enable GitHub Pages: Settings > Pages > Branch: main
4. Setup Giscus at https://giscus.app for comments

## Configuration

See `_config.yml` for all options.

## Integration with Cyber Silicon Suite

Use with `blogger_fb_publisher_v2.py`:

```bash
python blogger_fb_publisher_v2.py
```

Automatically publishes from `queue/*.md` to `_posts/`
